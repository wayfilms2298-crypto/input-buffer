# Input Buffer

Tapped a hair too early and the cube just... didn't jump? This mod keeps very short taps "held" for a few extra milliseconds, so a click that lands just before you touch the ground or an orb still counts.

- Adjustable buffer window (default 80 ms)
- Per-gamemode toggles (ship, wave and swing are never buffered)
- Never extends a tap that already did something, so no accidental double jumps
- Optional "practice mode only" setting

Note: input-assist mods like this may not be allowed for list or leaderboard submissions. Check the rules before submitting a completion.
